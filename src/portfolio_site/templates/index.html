How this was built

I designed each of these projects and made the calls in it: what to measure, against which baseline, and what to do when a test came back wrong. I used AI coding assistants for implementation and drafting, which is now ordinary practice in software and machine learning work. Every number in every results table is reproducible from its repository with one command, and each repository also records one approach that was tried and did not work, with the evidence.
